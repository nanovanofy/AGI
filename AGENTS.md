- Packages : model, dao, service, util, view. Architecture en couches.
- Requêtes SQL toujours avec PreparedStatement.
- Interface en français, thème orange (#C2570C, fond #FFF7ED).
- Code simple, commenté en français, adapté à un étudiant.
- Après chaque étape : le projet doit compiler (mvn compile).
- Ne modifie que ce que je demande. Pas de nouvelle bibliothèque sans me prévenir.
